## 🔧 Setup Walkthrough

### Step 1 — Download the Pack
Grab the theme bundle archive.

### Step 2 — Open VS Code
Launch the editor and open the Extensions panel.

### Step 3 — Install from VSIX
Click the three-dot menu → "Install from VSIX" → pick a theme.

### Step 4 — Choose the Theme
Press `Ctrl + K` then `Ctrl + T` and select your new theme.

### Step 5 — Add an Icon Pack
Install a matching icon theme for a consistent look.

### Step 6 — Sync Settings
Enable Settings Sync to carry your theme across devices.
